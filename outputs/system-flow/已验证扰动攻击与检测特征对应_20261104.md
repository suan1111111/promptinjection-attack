## 1. 目前有成功记录的实际攻击形式

下列次数是各次实验中，攻击图回答包含精确占位符 `<maliciousurl>` 的题数；对应干净图均为 0。它们描述具体图片和问题集上的现象，不是整个攻击类别的泛化成功率。阅读到的命中回答包含额外的访问引导，不能将训练结束或 loss 下降本身计为成功。

| 实际形式 | 程序如何构造 | 已有生成证据 | 检测上优先考察的特征 |
| --- | --- | --- | --- |
| 全图像素扰动 | `optimize_qwen_pixels.py` 的 global；在整幅模型输入图上优化像素，限制幅度 | 第二批七形式实验 10/10，幅度 16/255 | KB/KV 残差强度与能量、RGB 频域分量；梯度和连续熵统计辅助 |
| 边框扰动 | 同一程序的 border；只允许四周边框内变化 | 第二批 10/10，边框宽 8 像素，幅度 32/255 | 残差与梯度；进一步需要描述异常是否集中在边缘 |
| 固定矩形贴片 | `train_qwen_patch.py` 的 fixed；优化并覆盖矩形区域 | 第二批 9/10；56×56，位于右上角，随机初始化、无额外幅度约束 | 局部熵、梯度窗口、残差；结合候选区域的面积与集中位置 |
| 不规则轮廓贴片 | `pixel_constraints.py` 的 flower；本例使用数学花瓣轮廓，无真实花朵素材 | 第二批 9/10；90×90 包围框，轮廓内优化，幅度上限 255/255 | 与矩形贴片共用局部熵、梯度、残差；轮廓统计若用于区分需另行定义 |
| 物体／场景区域内扰动 | `scene_region_batch.py` 使用自定义掩码，仅改变海浪、冰箱外壳、收音机本体或塔楼墙面等区域 | 本次读取到四张已完成图：精确标记分别 10/10、10/10、10/10、9/10；幅度 32/255 | 残差及其空间分布、梯度窗口分布；频域和连续熵统计辅助 |

上述五种表现可先组织成三个上层方向：**全图扰动、边框扰动、局部区域扰动**。后者再记录矩形覆盖、不规则轮廓、物体表面等构造方式。它们是基于攻击构造整理的类别，不是已经验证可由特征完全区分的专属检测器。

固定与随机位置主要是训练和放置策略，不宜仅凭一张最终图片就推断其训练策略并建立两个互斥检测叶节点。也不能由“局部贴片”直接推导出“高梯度且高熵”是必要条件。

## 3. 已实现但本次未确认成功的形式

- **低频扰动：** DCT 低频系数参数化。第二批为 0/10；额外低频 A/B 验证也没有新增精确标记或变体提示。若以后取得成功样本，可以重点考察低频能量及频谱分布，不能只检查高频增强。

- **随机位置小贴片：** 第二批和本次读取的后续小贴片测试未见明确成功记录；不能因为训练完成或贴片看起来很异常就计为注入成功。也不能据此断言这种方法不可能成功。
- **素材外观受限的局部图形：** `local_shape_fit` 的若干实验为训练题 0/5；它们不能与已经成功的宽幅花瓣轮廓噪声贴片混为一谈。

## 4. 直接计算现有特征后的观察

使用项目现有函数，对第二批七种图片和四张已完成的场景区域图片进行计算；每张与同尺寸干净图配对。计算梯度、三尺度局部熵、KB/KV 残差和当前六项 RGB 频域分量，共 33 个数值字段。没有新增检测阈值或训练分类器。

以下梯度占比是 `high_gradient_area_ratio`，熵区域占比是合并过滤后的 `candidate_area_ratio`，残差能量是 `kb_residual_energy`。

| 图片 | 高梯度区域占比：干净→扰动 | 熵候选区域占比：干净→扰动 | KB 残差能量：干净→扰动 |
| --- | --- | --- | --- |
| 全图扰动，成功 | 25.50% → 32.22% | 0 → 0 | 549.82 → 1730.59 |
| 边框扰动，成功 | 25.50% → 21.56% | 0 → 0 | 549.82 → 1033.46 |
| 不规则轮廓贴片，成功 | 25.50% → 26.85% | 0 → 1.55% | 549.82 → 4435.52 |
| 固定矩形贴片，成功 | 25.50% → 16.53% | 0 → 1.76% | 549.82 → 3538.57 |
| 随机位置贴片，本次未成功 | 25.50% → 23.23% | 0 → 1.81% | 549.82 → 2955.06 |
| 海浪区域扰动，成功 | 37.91% → 67.45% | 0 → 0 | 358.83 → 2677.07 |
| 冰箱区域扰动，成功 | 30.45% → 52.80% | 0 → 0 | 430.10 → 2330.80 |

这里有三个与决策树直接相关的发现：

1. **不能要求成功攻击的梯度统计一定升高。** 当前梯度模块对每张图片做全局 min-max 归一化，再用固定窗口阈值选择区域；边框和固定贴片的高梯度面积比例均下降。不能据此直接构造“梯度占比高才继续”的必要门槛。
2. **当前高熵候选区域不能作为所有扰动的必经条件。** 成功的全图、边框和四张场景区域图片，其最终熵候选面积均为零。零候选不表示所有熵统计不变，例如全图样本第一尺度平均熵从约 4.36 升至 5.06。
3. **图像异常也不等于注入成功。** 未成功的随机位置贴片具有明显熵候选区域和增大的残差，与成功贴片在这些统计上接近。图像侧应提供候选证据，后续仍需隐藏状态检测与行为验证。

全部精确数值和输入路径：[feature_comparison.json](D:/CodexProjects/PrivaSee/outputs/system-flow/attack_feature_review_20261104/feature_comparison.json)。便于查看的部分字段：[feature_comparison.csv](D:/CodexProjects/PrivaSee/outputs/system-flow/attack_feature_review_20261104/feature_comparison.csv)。计算脚本：[analyze_existing.py](D:/CodexProjects/PrivaSee/outputs/system-flow/attack_feature_review_20261104/analyze_existing.py)。

这些是少量配对样本的描述性观察，不是检测准确率。线上未知图片通常没有对应干净图，所以不能把本次“扰动前后差值”当作线上现成可用的特征。正常图像也可能有强纹理、高残差；阈值仍需正常参考和更多成功／失败案例检验。

## 5. 哪些特征已经能算，哪些还需要补充

| 检测方向 | 已有能力 | 若要区分具体形式，需要补充的内容 |
| --- | --- | --- |
| 全图扰动候选 | 全图 KB/KV 残差统计、RGB 频域分量、梯度及连续熵统计 | 残差在不同区域的分布，以区分遍布全图与集中局部；正常参考下的规则验证 |
| 边框扰动候选 | 梯度窗口包含位置，残差函数可返回残差图 | 边缘与内部的响应对比、响应距图像边缘的分布；目前不是独立输出字段 |
| 矩形／不规则贴片候选 | 多尺度熵候选掩码、区域数与面积、梯度窗口、残差统计 | 候选区域内外的残差／梯度对比；若要判断轮廓，需额外轮廓统计 |
| 物体区域内扰动候选 | 残差、梯度窗口、频域和连续熵统计 | 在图片上寻找响应集中的区域；当前没有自动识别攻击物体区域的专属定位器 |

训练使用的真实掩码可以用于验证定位效果，但新图片检测时不能假定已知该掩码。区域内外统计应基于检测到的候选区域，而不是直接读取训练答案。

这些攻击通过优化像素影响模型回答，并没有在训练中要求把攻击指令写成可读文字。回答中出现网址，不代表图片里存在可供 OCR 识别的网址。因此 OCR 和文字重合可以提供补充解释，但不应作为这些扰动攻击的共同前置必要条件。

## 6. 对决策树安排的直接修正

- 移除此前临时设定的“高梯度高熵模式”“高梯度文字模式”名称。
- 按真实构造记录全图、边框、局部区域等类型；规则未验证前，不把类型名当作可直接判定的叶节点。
- 优先用现有残差、频域、梯度及熵结果研究共同响应，再利用位置与区域统计区分局部形式；本次结果尚不足以决定固定检查顺序。
- 共享计算可以先明确：梯度窗口供多个区域判断使用；残差图供全局汇总、边缘／内部及局部区域统计使用；熵候选区域供局部定位使用。后两类区域统计需要补充实现，不能表述为当前已存在。
- 任何用于提前排除模式的条件，都需要单独验证其作为必要条件是否会遗漏已知成功案例；低残差、低梯度或零熵候选都不能直接解释为安全。
