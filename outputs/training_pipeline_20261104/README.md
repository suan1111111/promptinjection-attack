# 训练队列和监护约定

先完成区域扰动的 10 张有效原图，再启动全局扰动。全局批次已经准备了相同 22 张原图及其同名 CSV，初始参数采用此前成功的全局设置：16/255 幅度、1/255 步长、四题平均梯度、40 道完整训练题、1000 次更新。目标列沿用已授权的多种原任务选择。

五分钟线程监护已创建，标识 automation。读取 plan.json 中的状态目录和命令，检查实际进程与文件更新时间，异常时先排除重复进程，再从检查点恢复。运行状态未变化时保持安静。电脑和 Codex 须保持运行。其他类型沿用这里的训练验证标准，待类型和顺序明确后加入队列。
