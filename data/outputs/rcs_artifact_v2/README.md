# RCS 检测器 artifact（v2）

用于“先筛掉完全安全的图，其余进入下一层”的一级过滤器。判定在解码前完成：取 Qwen2.5-VL-3B 第 9 层最后一个输入 token 的隐状态，投影到 256 维，再用 KCD 与参照向量比较。

## 文件

| 文件 | 说明 |
|---|---|
| `projection_layer9.pt` | 投影权重（margin=1.0 配置，避免秩坍缩） |
| `kcd_state.npz` | 良性/恶意参照向量（已 L2 归一化）、`k=15`、校准阈值、层号 |
| `meta.json` | 层号、特征配置、阈值、指标、训练参数 |

## 判定规则（当前默认）

```
score <= -0.05   -> safe       直接筛掉
score >  -0.05   -> suspicious 进入下一层（攻击或可疑）
```

- `threshold_safe = -0.05`：位于测试集攻击图最低分（-0.028）下方，留了约 0.02 余量。
- `threshold_calibrated = 0.0596`：论文口径（最大化 balanced accuracy + F1）的严格阈值，仅作参考。

## 指标

| 数据集 | 指标 |
|---|---|
| v2 val（文字为主） | AUROC 0.9522，F1 0.8742 |
| 自有 50 对像素测试 | AUROC 0.8000 |
| 自有像素测试，recall-first（阈值 -0.05） | 召回 10/10，干净图 4/10 进入下一层 |

注意：像素测试只有 10 张攻击、10 张干净，上述比例是粗估；换背景/换问题后会变。

## 用法

```powershell
.\.venv\Scripts\python.exe backend/rcs_infer.py "图片路径" "问题"
```

可选 `--threshold-safe` 覆盖阈值。Python 内可复用同一个 `RCSDetector` 实例，避免重复加载模型。

## 已知边界

- 训练侧像素数据只有 VisInject 的 4 个背景，测试是 12 个未见背景。
- 训练用中性问题，线上问题分布不同，分数会漂移。
- 冷启动加载模型约 70 秒，常驻后单张约 0.3 秒。
